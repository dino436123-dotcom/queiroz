# Fotografias da Barbearia Queiroz

As fotos enviadas foram organizadas aqui e aparecem automaticamente na galeria:

- `entrada.jpg` — entrada e letreiro vistos de dentro
- `interior.jpg` — cadeiras e iluminação geométrica
- `corte-01.jpg` — barbeiro atendendo um cliente
- `equipe.jpg` — equipe e clientes em atendimento
- `produtos.jpg` — produtos expostos na barbearia
- `area-espera.jpg` — área de espera
- `letreiro.jpg` — detalhe do letreiro Queiroz

A fachada está representada pelo clipe real `../videos/fachada-da-loja.mp4`; não foi enviada uma foto externa separada.

As imagens copiadas do Google Maps não foram incluídas. Adicione somente fotos próprias ou autorizadas. Para novas fotos, JPG com lado maior entre 1600 e 2400 px funciona bem; Next/Image faz a otimização para a página. Em produção, rode `npm run build` depois de adicionar ou substituir fotos.
